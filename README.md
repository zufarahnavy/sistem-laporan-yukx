- Isi `js/config.js` dengan URL Web App Apps Script (`.../exec`). Selama belum diisi, aplikasi berjalan dalam **Mode Demo**.
- Akun demo (PIN 123456): `admin@yukbanyuwangi.demo` · `finance@yukbanyuwangi.demo`.
- Gambar bawaan halaman masuk ada di `assets/login/` (ilustrasi). Ganti dengan foto sendiri lewat **Pengaturan → Halaman masuk**.
- Panduan lengkap: `PANDUAN-INSTALASI-v2.1.0.md` (diberikan terpisah).

Tidak ada token, kunci, atau ID file di folder ini — semuanya (termasuk token WhatsApp Business API dan Client ID/Secret Mekari untuk Qontak) disimpan di Script Properties backend.
